# 🍅 Tomato Leaf Disease Prediction

## 📌 Overview
This project focuses on detecting and classifying tomato leaf diseases using machine learning / deep learning techniques. The model analyzes images of tomato leaves and predicts whether the plant is healthy or affected by a specific disease.

Early detection helps farmers take timely action to improve crop yield and reduce agricultural loss.

---

## 🚀 Features
- Image-based plant disease detection
- Classification of multiple tomato leaf diseases
- High accuracy using deep learning models (CNN)
- Easy-to-use prediction pipeline
- Can be extended for real-time mobile/web applications

## 🌿 Dataset
The model is trained on a dataset containing images of tomato leaves with different conditions such as:

- Early blight
- Late blight
- Leaf mold
